# secrets-bridge / agent

Outbound-only execution agent. Runs inside a target account / cluster with least-privilege credentials. **No Postgres, no Redis** — imports only core/providers + core/sync.

🚧 **Scaffold in progress.** See [issue #1](https://github.com/secrets-bridge/agent/issues/1) for the open work and acceptance criteria.

See the [org profile](https://github.com/secrets-bridge) for the platform overview.
